# workflow
전체 해야할일
- 입력 : "/Users/yujin/Desktop/성현회계법인/담보물배분표/datas/공장저당법목록.pdf"
- 출력 : "담보물배분표/output/mortgage_list/공장저당법목록.json"


## 1. llm 문서 기반 파서
문서 구조를 토대로, 가계기구 목록 전체 pdf에서 상대적으로 작은 llm인 gpt-5.4-mini 모델을 통해서 각 파트의 "페이지 번호 시작-끝"만 가져온다. 이를 토대로 1개의 큰 pdf를 output경로에 "담보물배분표/output/mortgage_list/공장저당법목록/" 경로에 여러 작은 pdf파일들로 분할한다.

## 2. llm 기반 고성능 파싱
각 분할된 pdf 파일들에 대해서 병렬로 처리한다. 고성능 llm인  gpt-5.6-sol 모델을 활용하고, detail="high"옵션으로 텍스트 인식 성능을 극대화한다. 이를 토대로 최종산출물인 "담보물배분표/output/mortgage_list/공장저당법목록.json"를 만든다.


# 금지사항
- 쓸데없는 모든 try-except등의 fallback 금지. 방어적 코딩금지
- llm 호출없는 기능 fallback 절대 금지
- llm 호출없이 실행성공은 테스트 실패.
- LangChain, Pydantic 기반 사용.
- 경로에 쓸데없이 실행기준 root 감지 금지. 
- 내가 하드코딩한 output_root, input_path 기반으로 경로 지정돼야함 
- 지정된 모델에 대해서 좃같은 env또는 환경변수 기반 지정아니고, 그냥 하드코딩 지정
