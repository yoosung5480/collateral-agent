# 공장저당법목록 문서 구조

* 부동산 등기사항전부증명서
* 공장 및 광업재단 저당법 제6조 목록 묶음

  * 목록 변경내역표
  * 목록 구분용 간지
  * 제6조 목록 표지
  * 기계기구목록
  * 목록 관련 부속 설명·확인 내용

## 반복 구조

`공장 및 광업재단 저당법 제6조 목록` 부분에는 서로 다른 목록번호의 문서 묶음이 반복된다.

```text
목록번호 A
├─ 목록 변경내역표
├─ 간지 또는 목록 표지
├─ 기계기구목록
└─ 부속 내용

목록번호 B
├─ 목록 변경내역표
├─ 간지 또는 목록 표지
├─ 기계기구목록
└─ 부속 내용
```

## Agent 파싱 기준

* 페이지 단위가 아니라 **목록번호**를 하나의 묶음을 구분하는 최상위 키로 사용한다.
* 새로운 목록번호가 나타나면 이전 목록 묶음을 종료하고 새 묶음을 시작한다.
* 각 묶음 내부에서 `목록 변경내역`, `제6조 목록`, `기계기구목록` 등의 제목과 표 구조를 식별한다.
* 실제 담보 기계기구 정보는 각 목록번호에 속한 `기계기구목록`에서 추출한다.
* 동일한 기계기구가 변경·삭제·추가되었는지는 해당 목록의 변경내역과 함께 판단한다.
* 문서 순서가 달라지거나 일부 표지가 누락되어도 **목록번호와 기계기구 표의 열 구조**를 근거로 묶음을 복원한다.

핵심은 `페이지 → 구간`이 아니라 **`문서 제목·표 구조 → 문서 유형`, `목록번호 → 반복 묶음`**으로 파싱하는 것이다.
