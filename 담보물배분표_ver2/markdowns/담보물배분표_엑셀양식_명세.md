# 담보물 배분표 Excel 양식 명세

## 0. 문서 목적과 범위

이 문서는 `담보물배분표예시.xlsx`의 형식을 코드에 내장하여, 이후에는 별도 Excel 템플릿 없이 `title.json`과 `encumbrance.json`만으로 동일한 형태의 워크북을 생성하기 위한 구현 명세이다.

이 문서에서 설명하는 범위는 다음 3개이다.

1. Excel 전체 구조
2. 부동산 담보물 배분표
3. 기계기구 담보물 배분표
---

## 1. 입력 JSON 구조

### 1.1 등기부 단위 구성

하나의 등기부는 다음 두 JSON으로 구성된다.

| 파일 | 역할 |
| --- | --- |
| `title.json` | 부동산 종류, 소재지, 면적·구조 등 담보물 자체의 정보 |
| `encumbrance.json` | 근저당권의 설정일자, 채권최고액, 채권자, 공동담보 여부, 저당법 목록번호 |

파일명 자체로 짝을 맞추지 말고, 각 JSON의 `registry_id`에서 `registry_01`, `registry_02`와 같은 등기부 식별자를 추출하여 연결해야 한다.

### 1.2 `title.json`

| 필드 | 의미 | Excel 사용 위치 |
| --- | --- | --- |
| `registry_id` | 원본 등기부 식별 경로 | JSON 연결 및 정렬 |
| `property_type` | `토지`, `건물` 등 부동산 종류 | 부동산 표 A열·B열의 분류 |
| `location` | 부동산 소재지 | 부동산 표 A열·B열 |
| `details` | 지목, 면적, 건물 구조 및 층별 면적 | 부동산 표 B열 |

### 1.3 `encumbrance.json`

`mortgages`는 담보설정 항목 배열이다.

| 필드 | 의미 | Excel 사용 위치 |
| --- | --- | --- |
| `registration` | 담보 설정일자 | D열 |
| `maximum_claim` | 채권최고액 | 배분내역의 `설정금액` |
| `mortgagee` | 근저당권자·채권자 | E열 및 배분내역의 `설정자` |
| `shared_collateral` | 공동담보 여부 | F열 |
| `mortgage_list_no` | 공장 및 광업재단 저당법 목록번호 | 기계기구 표 B열 |

### 1.4 값 처리 원칙

- 날짜는 문자열 그대로 Excel에 쓰지 말고 실제 날짜 값으로 변환한다.
- 금액은 `금 5,040,000,000원`에서 숫자만 파싱하여 정수 `5040000000`으로 저장한다.
- `공용담보`, `공동담보`, `공담`은 Excel 표시값 `공담`으로 통일한다.
- JSON으로 확인할 수 없는 가치평가액, 배분액, 배분잔액, 기계기구 수량 및 감정금액은 추정하지 않고 공란으로 둔다.

# 2. Excel 전체 구조

## 2.1 워크북 구조

- 워크북은 기본적으로 시트 1개로 구성한다.
- 표 작성 영역은 고정된 16개 열 `A:P`를 사용한다.
- 열은 고정하고, 부동산 그룹 수와 담보권 수에 따라 행만 동적으로 증가시킨다.
- 원본 양식의 시트 확대 비율은 61%이다.
- 원본 양식에는 틀 고정이 없다.
- 기본 글꼴은 `맑은 고딕`이다.

## 2.2 전체 세로 배치 순서

| 순서 | 영역 | 반복 여부 |
| --- | --- | --- |
| 1 | `채무자 : {채무자명}` | 문서 최상단 1회 |
| 2 | `<부동산 담보물 배분표>` | 전체 부동산 영역에서 1회 |
| 3 | 부동산 담보물 배분표 그룹 1 | 필수 |
| 4 | 부동산 담보물 배분표 그룹 2 이상 | 담보설정현황 그룹 수만큼 반복 |
| 5 | `채무자 : {채무자명}` | 기계기구 영역 시작 시 다시 1회 |
| 6 | `<기계기구 담보물 배분표>` | 1회 |
| 7 | 기계기구 담보물 배분표 | 1회 |
| 8 | 기계기구 담보물 배분표 대조표 | 뒤에 배치되지만 이번 문서의 상세 구현 범위에서는 제외 |

중요한 점은 **부동산 표가 여러 개여도 `<부동산 담보물 배분표>` 제목을 표마다 반복하지 않는 것**이다. 원본에서는 부동산 영역 시작 시 한 번만 표시한다.

## 2.4 공통 표 머리글

각 부동산 그룹 표와 기계기구 표는 같은 2행 머리글을 사용한다.

| 병합 범위 | 표시값 |
| --- | --- |
| A열, 머리글 2행 세로 병합 | `담보물 소재지` |
| B열, 머리글 2행 세로 병합 | `담보물 내역 (담보물의 면적 및 수량)` |
| C:F, 첫 번째 머리글 행 가로 병합 | `담보설정현황` |
| C, 두 번째 머리글 행 | `순위` |
| D, 두 번째 머리글 행 | `설정일자` |
| E, 두 번째 머리글 행 | `채권자` |
| F, 두 번째 머리글 행 | `공담` |
| G열, 머리글 2행 세로 병합 | `가치평가액 (주1)` |
| H:O, 머리글 2행 전체 병합 | `배분내역` |
| P열, 머리글 2행 세로 병합 | `비고` |

머리글 서식은 다음과 같다.

- 글꼴: 맑은 고딕 10pt, 굵게
- 배경색: `#B7DEE8`
- 정렬: 가로·세로 가운데
- 긴 텍스트: 줄바꿈
- 테두리: 모든 방향 얇은 실선
- 각 머리글 행 높이: 21pt

## 2.5 공통 본문 행 생성 규칙

담보권 수를 `n`이라고 할 때 배분내역은 한 블록에 담보권 2개를 표시하며, 한 블록은 3행을 사용한다.

```text
배분 블록 수 = ceil(n / 2)
본문 최소 행 수 = 배분 블록 수 × 3
본문 실제 행 수 = max(n, 본문 최소 행 수)
```

현재 예시처럼 담보권이 6개라면 다음과 같다.

```text
ceil(6 / 2) = 3개 블록
3개 블록 × 3행 = 본문 9행
```

본문에서 A, B, G, P열은 본문 전체 높이만큼 각각 세로 병합한다. C:F는 담보권 하나당 한 행씩 기록하며, 담보권 기록이 끝난 뒤 남는 행은 공란으로 둔다.

### 배분내역 3행 블록

| 행 | H:K 영역 | L:O 영역 |
| --- | --- | --- |
| 1행 | `1순위`처럼 홀수 순위 제목을 H:K 병합 | `2순위`처럼 짝수 순위 제목을 L:O 병합 |
| 2행 | `설정자`, `설정금액`, `배분액`, `배분잔액` | 동일 |
| 3행 | 채권자, 채권최고액, 공란, 공란 | 채권자, 채권최고액, 공란, 공란 |

담보권 수가 홀수이면 마지막 블록의 오른쪽 L:O 영역은 공란으로 둔다.

## 2.6 공통 서식

- 표 제목: 맑은 고딕 16pt, 굵게, 가운데 정렬
- 일반 본문: 맑은 고딕 11pt
- 설명·각주: 맑은 고딕 10pt
- 표 전체: 얇은 검정 실선 테두리
- A·B열 본문: 세로 가운데, 자동 줄바꿈
- C:F 및 H:O: 가로·세로 가운데
- G열 및 금액 셀: 우측 정렬, 천 단위 쉼표
- 날짜: Excel 날짜형 값으로 저장
- 본문 행 높이:
  - 긴 토지·건물 내역 또는 기계기구 목록이 있는 경우 50pt
  - 짧은 단일 부동산 표는 40pt까지 줄일 수 있음
- 표 사이에는 최소 1개 이상의 빈 행을 둔다.

## 2.7 데이터 병합과 정렬

### 등기부 연결

1. `registry_id`에서 `registry_XX`를 추출한다.
2. 같은 식별자의 `title.json`과 `encumbrance.json`을 하나의 등기부 레코드로 연결한다.
3. 한쪽 JSON이 없거나 중복되면 자동 추정하지 말고 오류로 처리한다.

### 담보설정현황 그룹화

부동산 표의 수는 등기부 수가 아니라 **서로 다른 담보설정현황의 수**이다.

두 등기부의 `mortgages` 배열에서 아래 5개 값이 순서까지 포함하여 모두 같으면 동일 그룹으로 본다.

1. `registration`
2. `maximum_claim`
3. `mortgagee`
4. `shared_collateral`
5. `mortgage_list_no`

현재 제공된 데이터의 병합 결과는 다음과 같아야 한다.

| 부동산 표 | 포함 등기부 | 결과 |
| --- | --- | --- |
| 그룹 1 | `registry_01`, `registry_03`, `registry_04` | 토지 1건과 건물 2건을 한 표에 병합 |
| 그룹 2 | `registry_02` | 별도 토지 표 |

따라서 등기부는 4개이지만 부동산 담보물 배분표는 총 2개가 생성된다.

### 순서

- 그룹 자체는 가장 먼저 등장한 `registry_XX` 순서를 유지한다.
- 그룹 내부 부동산은 `토지 → 건물 → 기타` 순으로 배치한다.
- 담보설정의 `순위`는 중요도나 법률상 우선순위를 새로 추론한 값이 아니다.
- `registration` 날짜 오름차순으로 정렬한 뒤 `1, 2, 3, ...`을 부여한다.
- 같은 날짜의 항목은 원본 `mortgages` 배열 순서를 유지한다.

## 2.8 확정값과 공란값

| 항목 | 현재 JSON으로 입력 가능 | 처리 |
| --- | --- | --- |
| 채무자명 | 별도 함수 인자로 가능 | 입력값 사용 |
| 담보권자 | `mortgagee` | 입력 가능 |
| 소재지·담보물 내역 | `title.json` | 입력 가능 |
| 순위·설정일자·채권자·공담 | `encumbrance.json` | 입력 가능 |
| 설정금액 | `maximum_claim` | 입력 가능 |
| 저당법 목록번호 | `mortgage_list_no` | 입력 가능 |
| 가치평가액 | 현재 등기부 JSON에는 없음 | 공란 |
| 배분액 | 없음 | 공란 |
| 배분잔액 | 없음 | 공란 |
| 감정평가 기준일·평가기관 | 없음 | 특정 날짜나 기관을 복사하지 말고 일반 안내문 또는 공란 |

# 3. 부동산 담보물 배분표

## 3.1 영역 구성

부동산 영역의 시작 구조는 다음과 같다.

| 상대 행 | 내용 |
| ---: | --- |
| 1 | `채무자 : {채무자명}` |
| 2 | A:P 병합 후 `<부동산 담보물 배분표>` |
| 3 | A열 `담보권자 : {담보권자}`, O:P 병합 후 `(단위:원)` |
| 4~5 | 공통 2행 머리글 |
| 6~ | 담보권 수에 따라 변하는 본문 |
| 본문 다음 행 | 가치평가액 관련 각주 |

두 번째 부동산 그룹부터는 문서 제목과 채무자 행을 반복하지 않는다. 다음 그룹은 빈 행을 둔 뒤 `담보권자` 행부터 다시 시작한다.

## 3.2 열별 입력 규칙

| 영역 | 입력 내용 | 생성 규칙 |
| --- | --- | --- |
| A | 담보물 소재지 | 같은 그룹의 부동산을 `property_type`별로 묶어 `<토지>`, `<건물>` 헤더 아래 나열 |
| B | 담보물 내역 | 각 부동산에 번호를 붙이고 `location`과 `details`를 함께 표시 |
| C | 순위 | 날짜순 정렬 결과에 따라 1부터 연속 번호 |
| D | 설정일자 | `registration` |
| E | 채권자 | `mortgagee` |
| F | 공담 | `shared_collateral`을 `공담`으로 정규화 |
| G | 가치평가액 | 현재 JSON만 사용할 때 공란 |
| H·L | 각 담보권의 설정자 | 각 블록의 세 번째 행에 `mortgagee` |
| I·M | 설정금액 | `maximum_claim`을 정수로 변환 |
| J·N | 배분액 | 공란 |
| K·O | 배분잔액 | 공란 |
| P | 비고 | 공란 |

## 3.3 A열 소재지 표시 형식

```text
<토지>
경상남도 함안군 칠서면 계내리 12

<건물>
건물 소재지 1
건물 소재지 2
```

동일한 `property_type` 헤더는 한 번만 표시한다.

## 3.4 B열 담보물 내역 표시 형식

```text
<토지>
1. 경상남도 함안군 칠서면 계내리 12
- 공장용지 10934㎡

<건물>
1. 건물 소재지 1
- 건물 상세 내용

2. 건물 소재지 2
- 건물 상세 내용
```

`details`는 원문 정보를 보존하되 줄바꿈을 사용하여 읽을 수 있게 표시한다. JSON에 없는 가치평가액을 B열 하단에 임의로 추가하면 안 된다.

## 3.5 담보권과 배분 블록의 관계

왼쪽 C:F에는 담보권 1개당 한 행을 사용한다. 오른쪽 H:O에서는 같은 담보권들을 2개씩 묶어 3행 블록으로 표시한다.

예를 들어 담보권이 6개인 경우:

| 배분 블록 | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| 블록 1 | 1순위 | 2순위 |
| 블록 2 | 3순위 | 4순위 |
| 블록 3 | 5순위 | 6순위 |

각 블록의 설정금액은 순위에 대응하는 `maximum_claim`이어야 한다. 서로 다른 순위의 금액이 섞이면 안 된다.

## 3.6 부동산 각주

원본 예시에는 특정 감정평가 기준일과 평가기관이 적혀 있지만, 이 값은 현재 JSON에서 오지 않는다. 따라서 자동 생성 시 다음 중 하나를 사용한다.

```text
(주1) 가치평가액 및 배분내역은 별도 감정평가 자료 입력이 필요합니다.
```

또는 전체 각주 행을 공란으로 둔다. 원본 예시의 특정 날짜·기관명을 고정값으로 복사해서는 안 된다.

# 4. 기계기구 담보물 배분표
## 4.1 대상 담보설정 그룹 선택

기계기구 표는 `mortgage_list_no`가 존재하는 담보설정현황 그룹을 사용한다.

현재 데이터처럼 여러 그룹에 목록번호가 일부 존재할 수 있으면 다음 기본 규칙을 사용한다.

1. 비어 있지 않은 `mortgage_list_no`가 가장 많은 그룹을 선택한다.
2. 개수가 같으면 먼저 등장한 `registry_XX` 그룹을 선택한다.

현재 데이터에서는 목록번호 6개를 가진 `registry_01·03·04` 병합 그룹이 선택되어야 한다.

향후 입력에서 기계기구와 부동산 그룹의 연결을 명시하는 별도 필드가 생기면, 이 휴리스틱보다 명시적 연결값을 우선해야 한다.

## 4.3 영역 구성

| 상대 행 | 내용 |
| ---: | --- |
| 1 | `채무자 : {채무자명}` |
| 2 | A:P 병합 후 `<기계기구 담보물 배분표>` |
| 3 | 빈 행 |
| 4 | `담보권자 : {담보권자}` |
| 5~6 | 공통 2행 머리글 |
| 7~ | 담보권 수에 따라 변하는 본문 |
| 본문 다음 행 | 가치평가액 관련 각주 |
| 그다음 행 | 기계기구 목록번호 관련 각주 |

기계기구 표의 B열 머리글은 부동산 표와 달리 다음 문구를 사용한다.

```text
담보물 내역
(담보물의 면적 및 수량)(주2)
```

## 4.4 열별 입력 규칙

| 영역 | 입력 내용 | 생성 규칙 |
| --- | --- | --- |
| A | 기계기구 담보 소재지 | 선택된 그룹의 `location`을 중복 제거하여 줄바꿈으로 표시 |
| B | 기계기구 및 목록번호 | 기계기구 개수는 알 수 없으므로 `기계기구`라고 표시하고 순위별 목록번호를 나열 |
| C:F | 담보설정현황 | 부동산 표와 동일 |
| G | 가치평가액 | 현재 JSON만 사용할 때 공란 |
| H:O | 배분내역 | 부동산 표와 동일한 2순위×3행 블록 |
| P | 비고 | 공란 |

## 4.5 B열 표시 형식

현재 입력만 사용하는 경우:

```text
기계기구
1순위: 공장 및 광업재단 저당법 제6조 목록 제2012-399호
2순위: 공장 및 광업재단 저당법 제6조 목록 제2012-514호
3순위: 공장 및 광업재단 저당법 제6조 목록 제2012-515호
...
```

- 목록번호는 해당 담보권의 순위와 연결하여 표시한다.
- `mortgage_list_no`가 빈 담보권은 목록번호 줄을 만들지 않는다.
- 기계기구의 실제 개수가 별도 데이터로 들어오기 전에는 `기계기구10식`처럼 개수를 만들어 쓰지 않는다.

## 4.6 기계기구 각주

```text
(주1) 가치평가액 및 배분내역은 별도 감정평가 자료 입력이 필요합니다.
(주2) 담보설정된 기계기구 목록번호는 다음과 같습니다.
```

두 각주는 각각 별도 행으로 표시한다.
